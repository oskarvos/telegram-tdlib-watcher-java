Как использовать

  • Укажите ссылки или ID чатов (по одному на строку).
  • Выберите, какие типы данных сохранять.
  • Нажмите «Начать дамп». Схема БД будет создана автоматически.
  • Статус обновляется автоматически, процесс можно остановить.
