Готово к началу

Как использовать:

  • Введите ссылки или ID чатов (по одному на строку)
  • Выберите, какой контент нужно сохранить:
    • Фотографии - изображения (JPG, PNG, GIF)
    • Видео - видеофайлы (MP4, AVI, MOV)
    • Ссылки - URL из сообщений
    • Сообщения - текстовые сообщения
    • Текстовые документы - TXT, PDF, DOC, код (.py, .cpp, .java), скрипты (.bat, .sh)
    • Аудио файлы - MP3, WAV, OGG, голосовые сообщения, аудио документы
  • Нажмите "Начать дамп" для запуска процесса
  • Следите за прогрессом в индикаторе выполнения
  • Нажмите "Остановить" для отмены операции
